# Unified SGCA checkpoint

This directory contains the final Unified SGCA checkpoint used for the updated manuscript results.

- `unified_sgca_best.pt`: final dog-normal robustness fine-tuned checkpoint
- `training_history.csv`: June 2026 fine-tuning history
- `dataset_config.json`: June 2026 fine-tuning configuration

Older May 2026 report folders and the superseded `training_config.json` were moved to the private backup because they corresponded to the pre-fine-tuning checkpoint and contained stale external metrics.
